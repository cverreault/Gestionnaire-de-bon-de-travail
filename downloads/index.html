Dispatch2Go — application Android (version de test)

Télécharger l'app (APK)

  1. Ouvrez le fichier téléchargé. Android demande d'autoriser l'installation depuis cette source : acceptez.
  2. Lancez Dispatch2Go. L'adresse de l'espace est déjà remplie : touchez Continuer.
  3. Connectez-vous avec votre compte technicien.
